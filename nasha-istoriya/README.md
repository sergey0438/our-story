# Наша история ❤️

Романтическая мини-игра-квиз для девушки: стартовый экран с вашим фото, вопросы о вас двоих, романтические вставки, письмо в конверте, подарок — и секретная глава в волшебной книге, о которой она не узнает заранее.

Работает без сервера и базы данных: просто HTML, CSS и JavaScript. Подходит для GitHub Pages, открывается на iPhone, Android, iPad и компьютере.

---

## Что внутри

```
index.html          — сама игра
admin.html          — визуальный редактор (без программирования)
config.json         — ВСЕ настройки игры (вопросы, тексты, фото, режимы)
css/style.css       — оформление игры
css/admin.css       — оформление редактора
js/app.js           — логика игры
js/admin.js         — логика редактора
js/shared.js        — общие функции
js/config.js        — запасная копия настроек (для открытия без сервера)
assets/photos/      — ваши фотографии
assets/music/       — музыка (MP3)
.nojekyll           — служебный файл для GitHub Pages
```

## Как проходит игра

1. **Старт** — «У меня для тебя кое-что особенное ❤️», ваше фото в рамке, кнопка «Начать нашу историю».
2. **Вопросы** — 6 типов: один вариант, несколько вариантов, свободный текст, да/нет, вопрос с фотографией, выбор между двумя сценариями. Прогресс — сердечками, есть «Назад», «Пропустить» (для необязательных) и тёплая фраза после каждого ответа.
3. **Романтические вставки** между вопросами.
4. **Секретный финал** (включён по умолчанию):
   ложный финал «Вот и всё…» → экран темнеет → «Подожди…» → «Кажется, мы забыли одну главу… 📖» → волшебная книга (листается свайпом, нажатием на край страницы или стрелками) → запечатанный конверт с личным письмом → «Но это ещё не всё… 🎁» → подарок → «Продолжение следует… ♡».
5. **Обычный финал** (если секретный выключить): конверт с письмом → «Открыть сюрприз 🎁» → подарок.
6. **«Наша маленькая история»** — все её ответы, кнопки «Сохранить нашу историю» (текстовый файл) и «Поделиться» (системное меню телефона).

Прогресс сохраняется на её устройстве: если случайно обновить страницу или закрыть вкладку, история продолжится с того же места — и в вопросах, и внутри книги.

## 1. Как открыть проект локально

**Самый простой способ** — двойной клик по `index.html`. Игра откроется, но браузеры не разрешают странице читать `config.json` с диска, поэтому будут использоваться настройки из `js/config.js` (запасная копия).

**Правильный способ** — запустить маленький локальный сервер, тогда всё работает ровно как на GitHub Pages:

- **Windows / macOS / Linux с Python:** откройте терминал в папке проекта и выполните
  ```
  python -m http.server 8000
  ```
  (на macOS может понадобиться `python3`). Затем откройте в браузере `http://localhost:8000`.
- **Visual Studio Code:** установите расширение «Live Server», нажмите правой кнопкой на `index.html` → «Open with Live Server».

Редактор открывается по адресу `http://localhost:8000/admin.html`.

## 2. Как добавить фотографии

Есть два способа — оба работают в редакторе.

**Способ А (рекомендую): файл в папке.**
1. Положите фото в `assets/photos/`, например `assets/photos/us.jpg`.
2. В редакторе в нужном поле укажите путь `assets/photos/us.jpg`.
3. Пути пишите **без** `/` в начале — иначе фото не найдётся, если сайт лежит в подпапке репозитория.
4. Совет: перед загрузкой уменьшите фото до ~1500 px по длинной стороне — сайт будет быстрее открываться на телефоне.

**Способ Б: загрузка с устройства.** Кнопка «📷 Загрузить с устройства» сожмёт фото и встроит его прямо в `config.json`. Удобно, но настройки становятся тяжелее (браузер хранит черновик до ~5 МБ — размер видно во вкладке «Публикация»).

Где можно использовать фото: стартовый экран, любой вопрос, вопрос с фотографией, галерея, страницы книги, фото рядом с личным письмом, фотографии подарка (книг), последний экран.

Если фото нет или путь неверный, вместо него показывается аккуратная романтическая заглушка — сайт не ломается.

## 3. Как изменить вопросы

Откройте `admin.html` → вкладка **«Вопросы»**:

- **Добавить:** выберите тип внизу и нажмите «+ Добавить вопрос».
- **Изменить:** нажмите на вопрос — он развернётся. Можно менять текст, тип, обязательность, картинку, варианты ответа (с эмодзи), текст после ответа.
- **Варианты:** добавлять/удалять/переставлять сколько угодно (минимум 2). Для «Да/нет» и «Двух сценариев» вариантов всегда два.
- **Порядок:** стрелки ↑ ↓.
- **Удалить:** ✕ — редактор переспросит.
- **Дублировать:** ⧉.
- **Правильные ответы:** по умолчанию оценки нет. Если хочется, включите «Режим угадывания» во вкладке «Основное» и отметьте ✓ нужные варианты. Даже при «неправильном» ответе реакция остаётся тёплой.

Во всех текстах можно писать `{имя}` — подставится имя из вкладки «Основное».

## 4. Как пользоваться визуальным редактором

Вкладки:

| Вкладка | Что настраивается |
|---|---|
| Основное | имя девушки, основной цвет, анимации, режим угадывания, музыка, тексты кнопок, романтические фразы, экран с ответами |
| Стартовый экран | заголовок, подзаголовок, совместное фото, кнопка |
| Вопросы | все вопросы и варианты |
| Вставки | романтические фразы между вопросами: текст, после какого вопроса, вкл/выкл |
| Финал | обычный финал с конвертом, сюрприз (показать подарок / сохранить интригу), галерея |
| Секретный финал | вкл/выкл, все тексты, паузы, книга (название, цвет обложки), страницы (добавить, удалить, порядок, фото), личное письмо и фото, подарок, последний экран, кнопка «Просмотреть весь финал» |
| Публикация | скачать `config.json`, импорт, размер настроек, сброс |

**Важно понимать:** всё, что вы меняете в редакторе, сохраняется **только в вашем браузере** как черновик. На сайте ничего не меняется, пока вы не опубликуете `config.json` (пункт 5).

**Предпросмотр:** на широком экране справа есть «телефон» с живым предпросмотром — он обновляется сам после каждого изменения. Кнопки «С начала», «Финал», «Ответы» переносят в нужное место. Кнопка «Предпросмотр ↗» открывает предпросмотр в новой вкладке (на телефоне — только так). Ответы в предпросмотре хранятся отдельно и не смешиваются с настоящими.

**Музыка:** положите MP3 в `assets/music/` (например `music.mp3`), во вкладке «Основное» включите «Музыкальное сопровождение» и проверьте кнопкой «▶ Проверить файл». Браузеры запрещают автозапуск звука, поэтому музыка начинает играть после нажатия «Начать нашу историю», а включить/выключить её можно кнопкой ♫ в правом верхнем углу. Если файла нет, кнопка просто не появится.

## 5. Как экспортировать и опубликовать настройки

1. В редакторе нажмите **«Скачать config.json»**.
2. Замените им файл `config.json` в корне проекта (на компьютере или сразу на GitHub — см. ниже).
3. Если открываете игру двойным кликом без сервера — дополнительно скачайте **«js/config.js»** и положите его в папку `js/`.

**Заменить файл прямо на GitHub:** откройте репозиторий → «Add file» → «Upload files» → перетащите новый `config.json` → «Commit changes». GitHub заменит старый файл. Через 1–2 минуты сайт обновится (иногда нужно обновить страницу с очисткой кэша).

**Импорт:** во вкладке «Публикация» → «⬆ Импортировать JSON» — восстановит настройки из любого сохранённого `config.json`. Удобно хранить копии разных версий.

## 6. Как загрузить проект на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **«+» → «New repository»**. Название — любое, например `our-story`. Выберите **Public** (на бесплатном тарифе GitHub Pages работает только с публичными репозиториями). Нажмите «Create repository».
3. На странице репозитория нажмите **«uploading an existing file»** (или «Add file» → «Upload files»).
4. Перетащите **всё содержимое** папки проекта (не саму папку, а файлы и папки внутри: `index.html`, `admin.html`, `config.json`, `css`, `js`, `assets`, `README.md`, `.nojekyll`).
   - Файл `.nojekyll` скрытый: на macOS нажмите `Cmd + Shift + .` в Finder, чтобы его увидеть. Если не получится — не страшно, сайт работает и без него.
5. Нажмите **«Commit changes»**.

Можно и через GitHub Desktop или `git push` — результат тот же.

## 7. Как включить GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе «Build and deployment» → **Source: Deploy from a branch**.
3. **Branch: `main`**, папка **`/ (root)`** → **Save**.
4. Подождите 1–3 минуты. Вверху страницы Settings → Pages появится адрес сайта.

## 8. Как получить ссылку и отправить её девушке

Ссылка будет такого вида:

```
https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/
```

Например: `https://ivan.github.io/our-story/`.

Перед отправкой:

1. Откройте ссылку со своего телефона и пройдите игру целиком (проверьте фото, музыку и секретную главу).
2. После проверки сбросьте свой прогресс: в конце игры «Пережить нашу историю ещё раз» или в редакторе → «Публикация» → «Сбросить прохождение на этом устройстве». (Прогресс хранится на каждом устройстве отдельно — у неё всё начнётся с начала в любом случае.)
3. Отправьте ссылку в мессенджере. Ссылку на `admin.html` ей отправлять не нужно 🙂

## Приватность — важно

- **GitHub Pages — это публичный сайт.** Всё, что вы туда загрузите (фото, вопросы, письма, `config.json`), может увидеть любой, у кого есть ссылка, а у публичного репозитория — вообще кто угодно. Не публикуйте то, что не готовы показать. Страницы помечены `noindex`, чтобы поисковики их не показывали, но это не защита.
- **В редакторе нет пароля — и это сознательно.** Пароль, написанный на JavaScript, ничего не защищает: его видно в коде. Зато редактор и не может ничего испортить: изменения в нём видны только в браузере того, кто их сделал. Если не хотите, чтобы `admin.html` был на сайте, просто не загружайте его на GitHub (и `js/admin.js`, `css/admin.css`).
- **Ответы девушки никуда не отправляются.** Они хранятся только в её браузере. Вы не сможете посмотреть их удалённо — только если она сама нажмёт «Поделиться» или пришлёт сохранённый файл «Наша маленькая история.txt».

## Частые вопросы

**Изменил вопросы в редакторе, но на сайте всё по-старому.** Редактор меняет только черновик в вашем браузере. Скачайте `config.json` и замените файл в репозитории (пункт 5). Если уже заменили — подождите пару минут и обновите страницу.

**Фото не показывается.** Проверьте путь: регистр букв важен (`Us.JPG` ≠ `us.jpg`), без `/` в начале, файл действительно загружен в `assets/photos/` на GitHub.

**Хочу, чтобы секретного финала не было.** Редактор → «Секретный финал» → выключить. После вопросов откроется обычный финал с конвертом.

**Как пройти игру заново?** В конце — «Пережить нашу историю ещё раз» или «Начать заново» на экране с ответами.

**Анимации тормозят на старом телефоне.** Редактор → «Основное» → выключить анимации. Если на телефоне в настройках включено «Уменьшение движения», сложные анимации отключаются автоматически. Книга, письмо и все кнопки при этом полностью работают.

**Используются ли платные сервисы?** Нет. Единственное внешнее подключение — бесплатные шрифты Google Fonts (с кириллицей). Если они не загрузятся, сайт использует системные шрифты.

Пусть ей понравится ❤️
